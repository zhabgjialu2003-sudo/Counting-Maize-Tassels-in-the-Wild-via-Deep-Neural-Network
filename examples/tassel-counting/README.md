# Tassel-counting Examples

The `input/` directory contains representative maize-field images. The
`output/` directory contains annotated results generated by the tassel detector.

| Input | Expected annotated output |
|---|---|
| `DJI_0243 (2).JPG` | `DJI_0243 (2)_annotated.jpg` |
| `DJI_0298 (2)_0_0.JPG` | `DJI_0298 (2)_0_0_annotated.jpg` |
| `DJI_0408 (2)_0_1.JPG` | `DJI_0408 (2)_0_1_annotated.jpg` |
| `DJI_0617_0_0.JPG` | `DJI_0617_0_0_annotated.jpg` |
| `DJI_0836_1_1.JPG` | No committed annotated output |

These files were already part of the project repository before the directory
reorganization. Future additions must include explicit source and licence
information.
