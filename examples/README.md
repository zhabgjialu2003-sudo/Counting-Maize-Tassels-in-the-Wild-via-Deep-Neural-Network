# Example Images

This directory contains a small set of reviewable inputs and expected outputs
for demonstration and smoke testing. It is not a training dataset.

- [`tassel-counting/`](tassel-counting/) contains field-image inputs and their
  annotated tassel-counting results.
- [`disease-screening/`](disease-screening/) is reserved for close-up leaf
  examples that have clear redistribution rights and recorded expected results.

Do not add private user uploads or unlicensed web images. Every new public
example must record its source or team ownership and its permitted use.
